# Honor For Legends - 分层状态机架构

这是一个为类MOBA回合制对战游戏设计的分层状态机的需求文档，需要你去实现策略模块的设计。

角色的行为都是通过Role.action来确定的，大致可以分为移动，普通攻击，技能（包含攻击类技能，辅助类技能，移动类技能）。
每回合给角色分配这些信息，角色就能自己移动，你不需要关系之后的处理。

关于游戏和地图的状态，全部都会在state中，包括我方信息，敌方信息，地图信息等。

由于我没法给你其他部分的代码，你可以假定state和role中的游戏信息和角色动作信息。

## 策略模块

在我目前的实现中，只有对角色的单独的状态控制，比如roleattackstate, roleretreatstate, rolemovestate等。这样的代码非常不易于整体策略的制定和实现，也容易陷入状态切换的死循环。

我希望你设计策略（决策），感知以及动作的代码，使其
- 能够方便进行策略的新增，而不用关心具体的动作应该怎么实现，也就是将策略抽象出来
- 根据场上态势（敌我血量，兵线，塔，水晶），自动进行策略的切换。
- 多角色的协同，比如协同进攻，协同推塔，协同防守，回血。
